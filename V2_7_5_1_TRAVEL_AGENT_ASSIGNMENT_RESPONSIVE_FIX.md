# Dream Trawell CRM V2.7.5.1 - Travel Agent Assignment + Responsive Fix

## Changes

- Team Travel Agent cards now show **Already Assigned** when an agent already has an owner instead of leaving the assignment area blank.
- Where available, the assigned team member name is shown beside the state.
- Team Travel Agent table view now shows the same Already Assigned state.
- Team Travel Agent detail/profile page now shows the same Already Assigned state.
- Unassigned agents continue to show **Assign to Me**.
- Removed the large sticky Travel Agent filter panel that was covering card content on shorter displays such as 1368 x 768 while scrolling.
- Moved Clear Filters into the filter header so the 8 filter controls fit into two rows at common laptop widths, reducing vertical space.
- No login/authentication changes.
- Existing simplified role/team access behavior is preserved.
